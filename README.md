# 水中イヤホンOKプールマップ

神奈川・東京の公営プール／指定管理プールについて、**水中イヤホン（骨伝導・完全防水・内蔵メモリ型、例：Shokz OpenSwim Pro）**の持ち込み可否を調査し、地図上に色分け表示するシンプルなWebアプリです。

## 使い方

`index.html` を開くだけで動作します（ビルド不要、外部ライブラリはCDN読み込み）。

- 🟢 緑（確定OK）: 公式サイト・FAQ等で明確に持ち込み可と確認できた施設
- 🟡 黄（要確認候補）: 禁止物リストにイヤホンの明記がない等、可能性はあるが未確定の施設
- 🔴 赤（NG）: 電子機器・イヤホンの持ち込みを明確に禁止している施設

サイドバーの検索・フィルターで絞り込み、カードをクリックすると地図が該当施設にジャンプします。

## GitHub Pagesで公開する

1. このリポジトリの **Settings → Pages** を開く
2. **Source** を `Deploy from a branch` に設定
3. **Branch** を `main` / `/ (root)` に設定して Save
4. 数分後に `https://wwlapaki310.github.io/pool-earphone-map/` で公開されます

## データの更新

`index.html` 内の `POOLS` 配列を編集するだけで反映されます。各施設の `status`（ok/maybe/no）、`note`（根拠）、`url`（出典）を随時アップデートしてください。
